About this project

A practical portfolio of AI workflows, not prompt gimmicks.

This project showcases reusable skills that package product judgment into repeatable workflows. Each skill defines the task, required inputs, expected outputs, tool connections, and quality standards needed to make AI useful in real operating teams.

How each skill works

01

Define the repeatable job

Each skill starts with a concrete work product, such as a PRD, ticket breakdown, release note, or research brief.

02

Specify inputs and context

The skill names exactly what it needs: notes, docs, tickets, transcripts, APIs, policies, or customer feedback.

03

Generate structured outputs

The agent creates a usable artifact with consistent sections, clear decisions, open questions, and next steps.

04

Evaluate quality

Rubrics make the outputs reviewable, so the skill can improve beyond a one-off prompt.
