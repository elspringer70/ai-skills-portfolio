# Tools

This skill can operate as a standalone prompt or as part of a connected product workflow.

## Core Integrations

### Confluence

Use Confluence to:

- Publish PRDs
- Link requirements to decision logs
- Maintain product documentation
- Share drafts for cross-functional review

### Google Docs or Notion

Use docs tools to:

- Draft PRDs collaboratively
- Capture comments and edits
- Maintain templates
- Export versions for leadership review

### JIRA

Use JIRA to:

- Convert PRD requirements into epics, stories, and tasks
- Link tickets back to PRD sections
- Track readiness, dependencies, and delivery status
- Create implementation follow-ups from open questions

### Slack or Microsoft Teams

Use team chat to:

- Pull stakeholder feedback from threads
- Summarize decision conversations
- Draft alignment messages
- Collect answers to open questions

### Figma

Use Figma to:

- Link designs to PRD requirements
- Capture UX states and flows
- Review design gaps against functional requirements
- Connect screen-level work to product intent

## Optional Advanced Integrations

### Analytics Tools

Use analytics platforms to:

- Validate current-state pain points
- Define baseline metrics
- Recommend event tracking
- Monitor launch success and guardrails

### Customer Support Tools

Use support platforms to:

- Pull common pain points
- Identify user confusion patterns
- Create support-facing launch notes
- Track post-launch issues

### Compliance Knowledge Base

Use approved policies, checklists, or review notes to:

- Identify regulated product areas
- Flag copy or disclosure needs
- Capture compliance dependencies
- Avoid unsupported product claims

### GitHub

Use GitHub to:

- Reference technical constraints
- Connect implementation work to PRD requirements
- Review open pull requests related to the feature
- Support release note generation after launch

## One-Day Build

A simple version can be built as:

- A markdown prompt
- A sample input and output
- A form that accepts messy notes and returns a PRD
- Manual export to Google Docs, Notion, or Confluence

## Portfolio-Worthy Build

A stronger public version could include:

- A demo interface with synthetic fintech or AI product scenarios
- PRD generation with editable sections
- Export to markdown, JSON, or Confluence-ready format
- Requirement readiness scoring
- Open-question routing by function
- PRD-to-JIRA ticket handoff
- Evaluation examples comparing weak and strong PRDs
